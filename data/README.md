# ASoundJob - Company Directory

## Overview

This directory contains the master list of audio industry companies for the ASoundJob
job portal. Each entry includes a careers URL that the scraper uses to find job postings.

## File Structure

```
data/
  audio_companies_final.json   # Master company list (source of truth)
  schema.json                  # JSON Schema definition
  final_verification_report.md # Full verification report
  playwright_results.json      # Raw Playwright verification results

scripts/
  validate_companies.py        # Validate the JSON against schema
  add_company.py               # Add or update a company entry
  generate_companies.py        # Original data generator (auto entries)
  cleanup_json.py              # Pass 1: prefix-based dedup
  cleanup_pass2.py             # Pass 2: blacklist + product removal
  cleanup_final.py             # Pass 3: remove non-companies + bad URLs
  migrate_schema.py            # Migrate old format to new schema
  verify_phase1.py             # HTTP URL checking
  verify_phase2.py             # HTTP URL discovery
  verify_content.py            # Content verification
  merge_results.py             # Merge verification phases
  deep_crawl_v2.py             # Deep crawl (multi-language + sitemaps)
  fast_crawl.py                # Fast crawl for remaining sites
  follow_through.py            # Follow landing pages to ATS URLs
  merge_final.py               # Final merge of all verification results
  playwright_verify.py         # Playwright-based URL verification
```

## Data Schema

Each entry in `audio_companies_final.json`:

```json
{
  "name": "Company Name",
  "careers_url": "https://company.com/careers",
  "category": "Professional Audio & Live Sound",
  "verified": true,
  "source": "manual",
  "scrape_method": "http",
  "notes": "Optional notes about this entry"
}
```

### Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | string | Yes | Company name (unique, case-insensitive) |
| `careers_url` | string | Yes | Direct URL to careers/job listings page |
| `category` | string | Yes | One of 27 predefined categories (see schema.json) |
| `verified` | boolean | Yes | Whether the URL has been confirmed to load and contain job listings |
| `source` | string | Yes | `"manual"` (hand-added) or `"auto"` (script-generated) |
| `scrape_method` | string | No | `"http"` (simple request) or `"playwright"` (needs JS rendering) |
| `notes` | string | No | Free-form notes about this entry |

### How `verified` Works

- `true` — The URL was confirmed (via HTTP check or Playwright) to load successfully
  and contain careers-related content. The scraper should attempt to scrape it.
- `false` — The URL could not be confirmed. It may be wrong, dead, geo-blocked,
  or behind anti-bot protection. The scraper should skip it or try as a fallback.

### How `source` Works

- `"manual"` — You added or edited this entry by hand. The scraper trusts it
  unconditionally and never re-verifies the URL.
- `"auto"` — The entry was generated by the data collection scripts. The URL
  may be re-verified by future automated passes.

### How `scrape_method` Works

- `"http"` — The page works with a simple HTTP request (requests/curl).
  This includes ATS platforms (Greenhouse, Lever, Workday) that serve
  static HTML.
- `"playwright"` — The page requires JavaScript rendering to display job
  listings. The scraper must use Playwright (or a headless browser) for these.
- If absent, default to `"http"` and fall back to `"playwright"` on failure.

## Workflow

### Adding a new company

**CLI mode:**
```bash
python3 scripts/add_company.py \
  --name "My Audio Company" \
  --url "https://myaudio.com/careers" \
  --category "AI/ML Audio" \
  --verified \
  --method http \
  --notes "Found via LinkedIn"
```

**Interactive mode:**
```bash
python3 scripts/add_company.py
# Then follow the prompts
```

### Updating an existing company

```bash
python3 scripts/add_company.py \
  --name "My Audio Company" \
  --url "https://corrected-url.com/careers" \
  --category "AI/ML Audio" \
  --verified \
  --update
```

### Fixing a wrong URL

If you find a company with a bad URL, you can either:

1. Use `add_company.py --update` to fix it (sets `source` to `"manual"`)
2. Edit `data/audio_companies_final.json` directly, then run validation:

```bash
python3 scripts/validate_companies.py
```

### Validating the data

```bash
# Check for errors and warnings
python3 scripts/validate_companies.py

# Only show errors (suppress warnings)
python3 scripts/validate_companies.py --quiet

# Auto-fix sorting issues
python3 scripts/validate_companies.py --fix
```

### How the scraper should use this data

1. Load `audio_companies_final.json` at the start of each scrape cycle
2. Filter to entries where `verified == true`
3. Route to the appropriate worker based on `scrape_method`:
   - `"http"` entries -> lightweight HTTP workers (50+ concurrent)
   - `"playwright"` entries -> browser workers (5-10 concurrent)
4. For `verified == false` entries:
   - Optionally attempt them as fallback (try HTTP, then Playwright)
   - If a URL starts working, flip `verified` to `true`
5. Cache results per URL to avoid re-scraping brands that share a careers page
